# 本地开发环境

根据官方文档在 MacOS 上安装，

[https://www.anchor-lang.com/docs/installation](https://www.anchor-lang.com/docs/installation)

On Mac and Linux, run this single command to install all dependencies.

```bash
curl --proto '=https' --tlsv1.2 -sSfL [https://solana-install.solana.workers.dev](https://solana-install.solana.workers.dev/) | bash
```

Anchor CLI 安装失败，下面是提示，

> Installed Versions:
Rust: rustc 1.89.0 (29483883e 2025-08-04)
Solana CLI: solana-cli 2.2.21 (src:23e01995; feat:3073396398, client:Agave)
Anchor CLI: Not installed
Node.js: v24.5.0
Yarn: 1.22.22
> 

原因及解决办法，

The `anchor` executable is located within the `.avm/bin` directory inside your home folder. You need to tell Zsh to look in this location when you type a command.

Open your `.zshrc` file with a text editor.

```bash
nano ~/.zshrc
```

Add the following line to the end of the file:

```bash
export PATH="$HOME/.avm/bin:$PATH”
```

Save the file and exit the editor. To make the changes effective immediately in your current terminal session, run:

```bash
source ~/.zshrc
```
