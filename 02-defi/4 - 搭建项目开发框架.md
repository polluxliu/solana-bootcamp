# 4 - 搭建项目开发框架

创建一个名为 **defi** 的项目，我们将在该项目中添加多个子程序，用于后续的各个 defi 应用开发。

```rust
anchor init defi
```

该命令创建的项目名字为 defi，其中的子程序的名字也是 defi。其默认使用 **Mocha + Chai** 作为测试框架，会在根目录下的 `tests` 目录中添加一个 `ts` 测试文件。

我们通过下面的命令添加我们即将实现的 **拍卖** 子程序。在项目的根目录下运行下面的两个命令：

```rust
anchor new auction
```

添加完这个子程序之后，在根目录下的 tests 目录中为这个子程序添加测试文件。

**auction_platform.ts**

```tsx
import * as anchor from "@coral-xyz/anchor";
import {Program} from "@coral-xyz/anchor";
import {Auction} from "../target/types/auction";

describe("auction", () => {
    // Configure the client to use the local cluster.
    anchor.setProvider(anchor.AnchorProvider.env());

    const program = anchor.workspace.auction as Program<Auction>;

    it("Is initialized!", async () => {
        // Add your test here.
        const tx = await program.methods.initialize().rpc();
        console.log("Your transaction signature", tx);
    });
});
```

我们可以将 defi 这个默认创建的子程序删除。

- 删除 programs\defi 目录
- 删除 tests\defi.ts
- 在 Anchor.toml 中删除 `[programs.localnet]` 下的 `defi = "..."`
- 执行 `anchor clean` 把项目的所有编译产物清理掉，恢复到初始化状态

执行下面的命令：

```bash
anchor test
```

其输出如下：

```bash
  auction
Your transaction signature 5HSSZ5rTpUEStN2QcYxFQ6QUzbY4BAD6ov4LjBxYL4kHNgm4X3PntgtuAMnA9sf1ujjLgAD7DQED825ZUhuV9fb4
    ✔ Is initialized! (474ms)

  1 passing (980ms)
```

`anchor test` 命令做了以下工作：

- 启动一个全新的 **solana-test-validator** 实例
- 构建你的程序（`anchor build`）
- 将程序部署到本地验证器（`anchor deploy`）
- 运行在 **Anchor.toml** 中定义的测试脚本（`[scripts]`）
- 测试完成后关闭本地验证器

我们也可以使用手动开一个单独进程内的 solana-test-validator，但此时需要我们自己构建和部署程序。首先运行下面的命令启动一个 validator：

```bash
solana-test-validator
```

接着构建程序：

```bash
anchor build
```

然后将构建后的 `.so` 部署到该 validator 中：

```bash
anchor deploy
```

最后运行测试：

```bash
anchor run test
```
