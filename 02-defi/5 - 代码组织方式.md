# 5 - 代码组织方式

代码的组织方式如下：

```
programs/
└── auction/
    └── src/
        ├── instructions/
        │   ├── mod.rs
        │   ├── add_supported_token.rs
        │   ├── buy_now.rs
        │   ├── create_auction.rs
        │   ├── create_auction_house.rs
        │   ├── initialize_platform.rs
        │   ├── place_bid.rs
        │   └── settle_auction.rs
        │
        ├── state/
        │   ├── mod.rs
        │   ├── auction.rs
        │   ├── auction_house.rs
        │   └── platform.rs
        │
        ├── lib.rs
        ├── error.rs
        ├── Cargo.toml
        └── Xargo.toml
```

`lib.rs` 

**程序入口文件**（对应 Rust 的 crate 根文件）。它的主要作用有三个：

- **声明模块**
    
    使用关键字 `mod` 声明 `instructions`、`state`、`error` 三个顶层模块。其中 `instructions`、`state` 是目录模块，而 `error` 是文件模块。
    
    一个 .rs 文件就是一个模块，文件名就是模块名。
    
    目录本身不会自动成为模块，**必须加一个 `mod.rs` 文件**。目录名是模块名，而 `mod.rs` 作为入口。新的 Rust 版本中已不再强制要求添加 `mod.rs`，可以直接用 **同名文件夹** + **同名文件** 的方式，如 `foo.rs` + `foo/` → `foo` 模块。
    
- **声明 Program ID**
    
    每个 Solana 程序在链上都有唯一的地址（Program ID），用 `declare_id!` 宏指定。
    
- **定义程序逻辑入口**
    
    `#[program]` 宏中的函数就是on-chain 指令。
    

`instructions/`

存放 **on-chain 指令的实现**。一个指令对应一个 `.rs` 文件：

- `initialize_platform.rs` → 平台初始化
- `add_supported_token.rs` → 添加结算代币
- `create_auction_house.rs` → 创建拍卖行
- `create_auction.rs` → 创建拍卖
- `place_bid.rs` → 英式拍卖出价
- `buy_now.rs` → 荷兰拍卖买断
- `settle_auction.rs` → 拍卖结算
- `mod.rs`：
    
    代码如下：
    
    ```rust
    pub mod add_supported_token;
    pub mod buy_now;
    pub mod create_auction;
    pub mod create_auction_house;
    pub mod initialize_platform;
    pub mod place_bid;
    pub mod settle_auction;
    
    pub use add_supported_token::*;
    pub use buy_now::*;
    pub use create_auction::*;
    pub use create_auction_house::*;
    pub use initialize_platform::*;
    pub use place_bid::*;
    pub use settle_auction::*;
    ```
    
    `mod xxx;` 在 **Rust 中的作用是声明模块 (declare a module)**。编译器遇到 `mod xxx` 时，会去查找源文件：
    
    - `xxx.rs`
    - 或 `xxx/mod.rs`
    
    然后把这个文件里的内容编译进来，作为当前 crate 的一个子模块。
    
    在 `mod xxx` 前添加 `pub` 的意思是把这个模块 **导出**（public），让别的地方也能访问。
    
    `use` 将指定路径下的某个项目（函数、结构体、trait、模块等）引入到当前作用域。`*` 表示 glob import，即把模块里所有的 公共项目 (pub) 全部引入到当前作用域。`use` 只在当前作用域有效，在前面添加 ****`pub` 之后就会把引入的名字再往外暴露。这里 pub use xxx::* 的用途是把 `initialize_platform` 等文件模块里的所有**公共定义**（`pub struct`、`pub fn`、`pub enum` 等）都 re-export 到 `instructions` 这一层，这样你在外部使用时，就不需要再写 `::initialize_platform::`，而是可以直接用。比如原本需要这么写：
    
    ```rust
    use crate::instructions::initialize_platform::handler;
    ```
    
    而现在可以直接这么写：
    
    ```rust
    use crate::instructions::handler;
    ```
    
    这样的话：
    
    - 模块 **本身** 可以用 `crate::instructions::initialize_platform` 引用。
    - 模块 **内部的内容**（比如 `handler`、`InitializePlatform`）也可以直接用 `crate::instructions::handler`、`crate::instructions::InitializePlatform`。
    
    在 lib.rs 中使用 `use instructions::*` 将 instructions/ 的全部内容导入使用。
    

`state/`

存放 **链上账户的定义**，即 `#[account]` 数据结构：

- `platform.rs` → `Platform` 账户，存储平台级参数（费率、支持的代币、配置等）
- `auction_house.rs` → `AuctionHouse` 账户，存储某个拍卖行的配置
- `auction.rs` → `Auction` 账户，存储某次拍卖的信息（类型、状态、出价记录等）

`error.rs`

存放错误码。
