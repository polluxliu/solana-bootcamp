# 拍卖行相关的账户模型和指令设计

# 拍卖行配置

## 账户模型

```rust
#[account]
#[derive(InitSpace)]
pub struct AuctionHouse {
    // 所属平台
    pub platform: Pubkey,

    // 拍卖行管理员
    pub authority: Pubkey,

    // 支持的结算代币
    pub settlement_mint: Pubkey,

    // 拍卖行抽成费率，以 basis points 为单位
    pub fee_rate: u16,
    
    // 拍品 ID
    pub next_auction_id: u64,

    // 拍卖行创建时间戳，以秒为单位
    pub created_at: i64,

    // PDA bump
    pub bump: u8,
}
```

`pub platform: Pubkey`

该拍卖行所属的平台（Platform PDA 的地址）。

`pub authority: Pubkey`

该拍卖行的管理员。

`pub settlement_mint: Pubkey`

拍卖行所使用的**结算代币的 mint 地址**。所有交易（出价、成交、抽成）都将用这个代币结算。

`pub fee_rate: u16`

拍卖行抽成费率（basis points，bp）。`1 bp = 0.01%`。

`pub next_auction_id: u64`

链上程序内部维护的计数器，用作一次拍卖活动的 ID。

`pub created_at: i64`

账户的创建时间戳，单位是秒（Unix 时间）。

`pub bump: u8`

Program Derived Address 的 bump 值。

## 拍卖行创建指令的账户上下文

```rust
#[derive(Accounts)]
pub struct CreateAuctionHouse<'a> {
    #[account(
        seeds = [b"platform"],
        bump = platform.bump
    )]
    pub platform: Account<'a, Platform>,

    #[account(
        init,
        payer = authority,
        space = 8 + AuctionHouse::INIT_SPACE,
        seeds = [b"auction house", platform.key().as_ref(), authority.key().as_ref()],
        bump
    )]
    pub auction_house: Account<'a, AuctionHouse>,

    // 结算代币
    pub settlement_mint: Account<'a, Mint>,

    // 拍卖行 ATA
    #[account(
        init_if_needed,
        payer = authority,
        associated_token::mint = settlement_mint,
        associated_token::authority = auction_house
    )]
    pub auction_house_treasury_ata: Account<'a, TokenAccount>,

    // 拍卖行管理员 ATA
    #[account(
        mut,
        associated_token::mint = settlement_mint,
        associated_token::authority = authority
    )]
    pub authority_ata: Account<'a, TokenAccount>,

    // 平台 ATA
    #[account(
        mut,
        associated_token::mint = settlement_mint,
        associated_token::authority = platform
    )]
    pub platform_treasury_ata: Account<'a, TokenAccount>,

    #[account(mut)]
    pub authority: Signer<'a>,

    pub system_program: Program<'a, System>,

    pub token_program: Program<'a, Token>,

    pub associated_token_program: Program<'a, AssociatedToken>,
}
```

`pub platform: Account<'a, Platform>`

**平台账户 (Platform PDA)**。用来保证拍卖行是挂在某个平台下面的。

`pub auction_house: Account<'a, AuctionHouse>`

要新建的 **拍卖行账户 (AuctionHouse PDA)**。`seeds` 使用了平台地址和拍卖行管理员地址。

`pub settlement_mint: Account<'a, Mint>`

拍卖行使用的结算代币的 Mint Account。

`pub auction_house_treasury_ata: Account<'a, TokenAccount>`

**拍卖行资金库 (AuctionHouse PDA 的 ATA)**，用于存储拍卖行收取的 **抽成费用**。

- `associated_token::mint = settlement_mint`
    
    这个 ATA 存放的是哪种代币，这里是 `settlement_mint`。
    
- `associated_token::authority = auction_house`
    
    这个 ATA 是属于谁的，这里是 `auction_house`。
    

`pub authority_ata: Account<*'a*, TokenAccount>`

**拍卖行管理员的 ATA**。在创建拍卖行时，这个账户里的代币会被扣除并转给平台资金库，作为一次性创建费。

`pub platform_treasury_ata: Account<'a, TokenAccount>`

**平台资金库 (Platform PDA 的 ATA)**。拍卖行管理员支付的创建费会转入这里。

`pub authority: Signer<'a>`

**拍卖行管理员**。`Signer<'a>` 强制要求 **这个账户必须在交易里签名**。

- `Signer<’a>` 表示这个账户必须在交易里签名。这也说明，这个账户必须是有私钥的（有私钥才能签名），这通常就是钱包账户。
- 这个账户是`#[account(init, payer = ...)]` 里的 payer，需要支付新账户的租金，也会从其 SOL 余额中扣除。
- 这个账户是否是 fee-payer，取决于客户端代码在构造交易时指定。这里的这行代码并不能表示该账户是 fee-payer。

💡

fee-payer 或 init 的 payer，是需要花费 SOL 的。

1. 在 Solana 里，每一笔交易都会消耗 **交易手续费 (transaction fee)**。
- 至于谁来付这笔钱，由 `transaction.feePayer` 字段指定。
- **fee-payer** 的 SOL 余额会被扣除，支付给当前区块的 leader。
- 交易需要至少一个签名人。
- 每个交易有一个签名列表，是交易中需要签名的账户的签名。大部分客户端代码在构造交易时，都会把 fee-payer 放在第一个。

1. 创建新账户时，必须预存一笔 SOL 让账户 rent-exempt（免租金删除）。
- **谁来付？**`#[account(init, payer = ...)]` 里的 `payer`。

`pub system_program: Program<'a, System>`

Solana 系统程序。

`pub token_program: Program<'a, Token>`

SPL Token 程序。

`pub associated_token_program: Program<'a, AssociatedToken>`

SPL Associated Token Program。**这个程序负责推导 ATA 的地址，然后交给 system_program 和 token_program 去创建。**

## 拍卖行创建指令

```rust
pub fn handler(ctx: Context<CreateAuctionHouse>, args: CreateAuctionHouseArgs) -> Result<()> {
    let auction_house = &mut ctx.accounts.auction_house;

    auction_house.platform = ctx.accounts.platform.key();
    auction_house.authority = ctx.accounts.authority.key();
    auction_house.settlement_mint = ctx.accounts.settlement_mint.key();
    auction_house.created_at = Clock::get()?.unix_timestamp;
    auction_house.bump = ctx.bumps.auction_house;
    auction_house.fee_rate = args.fee_rate;
    
    // 初始化 auction_id，从 0 开始
    auction_house.next_auction_id = 0_u64;

    // 一次性费用收取
    let cpi_accounts = Transfer {
        from: ctx.accounts.authority_ata.to_account_info(),
        to: ctx.accounts.platform_treasury_ata.to_account_info(),
        authority: ctx.accounts.authority.to_account_info(),
    };
    let cpi_ctx = CpiContext::new(ctx.accounts.token_program.to_account_info(), cpi_accounts);
    transfer(cpi_ctx, ctx.accounts.platform.auction_house_creation_fee)?;

    Ok(())
}
```

这里用到了 **Cross Program Invocation**（跨程序调用）。其意思是一个程序在执行时调用另一个程序。在 Solana 上，每个程序都是独立的，如果你想转账代币，就必须调用 **SPL Token Program** 的 `transfer` 指令。

- `let cpi_accounts = Transfer { ... };`
    
    `Transfer` 是 `anchor_spl::token::Transfer` 结构体，表示调用 SPL Token Program 的 `transfer` 指令时需要的账户集合。
    
    - `from` → 代币来源账户，这里是 **拍卖行管理员的 ATA**（`authority_ata`）。
    - `to` → 代币接收账户，这里是 **平台的资金库 ATA**（`platform_treasury_ata`）。
    - `authority` → 代币来源账户这个 ATA 的 `data` 字段中的 `owner`，用来表示这个 ATA 是属于谁的。这里是 **拍卖行管理员钱包**（`authority`）。只有 `owner` 才能签名授权，从这个 Token Account 里转钱。
- `let cpi_ctx = CpiContext::new(...);`
    
    创建一个 **CPI 上下文**，告诉 Anchor：
    
    - 要调用哪个程序
    - 要带上哪些账户
    
    这里：
    
    - `ctx.accounts.token_program.to_account_info()` → 目标程序 = **SPL Token Program**
    - `cpi_accounts` → 上一步构造的转账所需账户
- `transfer(cpi_ctx, ctx.accounts.platform.auction_house_creation_fee)?`
    
    调用 SPL Token Program 的 `transfer` 指令。金额为 `platform.auction_house_creation_fee`，这是平台在初始化时设定的一次性拍卖行创建费。
    
    `?` 是 Rust 的错误传播符号：
    
    - 碰到 `Err` → 提前 `return`；
    - 碰到 `Ok` → 解包继续执行。
