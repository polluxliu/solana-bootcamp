# 准备测试环境

> 公开版说明：原文中的助记词和私钥示例已移除。请按教程在本地生成测试钱包，并替换代码中的占位内容。

测试代码的执行环境是 `localhost`，需要首先开启本地的运行环境：

```bash
solana-test-validator
```

然后生成下面的账号。

## 拍卖行管理员账户

使用下面的命令生成一个新的 keypair，用作拍卖行的管理员：

```bash
solana-keygen new --outfile ./auction-test-wallets/auction-house-admin-1.json --no-bip39-passphrase
```

其输出为：

```bash
Generating a new keypair
Wrote new keypair to ./auction-test-wallets/auction-house-admin-1.json
===================================================================================
pubkey: 7M6Kfyk8qig6fGqDmwADbhkwwb3qCMCbYZ9ByY6NZGpv
===================================================================================
Save this seed phrase to recover your new keypair:
[助记词已移除；请在本地生成自己的测试钱包]
===================================================================================
```

这只是 **在本地** 生成了一对公私钥（keypair）。此时其状态为 **unfunded**（未上链），这时链上没有任何记录。

使用下面的命令为该账户充值：

```bash
solana airdrop 10 7M6Kfyk8qig6fGqDmwADbhkwwb3qCMCbYZ9ByY6NZGpv
```

这样管理员账户就有了 10 SOL 的余额。可以使用下面的命令查看其余额：

```bash
solana balance 7M6Kfyk8qig6fGqDmwADbhkwwb3qCMCbYZ9ByY6NZGpv
```

链上交易的手续费、新建账户的租金都将由拍卖行管理员账户的 SOL 余额来支付。

## 平台支持的结算代币

使用下面的命令创建一个 Mint Account：

```bash
spl-token create-token
```

其输出如下：

```bash
Creating token D4qHfYe6MDh1cfR6ikWDYqhFNgBoKMVVtX8Trs27C1Xp under program TokenkegQfeZyiNwAJbNbGKPFXCWuBvf9Ss623VQ5DA

Address:  D4qHfYe6MDh1cfR6ikWDYqhFNgBoKMVVtX8Trs27C1Xp
Decimals:  9

Signature: 5f7LsBchptBBVr75cQfc3YJzhsqLbiq4vvcZjtRzxDBt6ZsNE2cJf3jCGn3GdegDkcv6TvXBb7t8hooHezhSQU6u
```

为当前钱包（Solana CLI 配置文件中的钱包）创建该代币的 ATA：

```bash
spl-token create-account D4qHfYe6MDh1cfR6ikWDYqhFNgBoKMVVtX8Trs27C1Xp
```

其输出如下：

```bash
Creating account qBuhWy9AHrCUh77iGDd2U23yndP8eay1FRGy8TGuhCf

Signature: 3jAcJxMCHMUv9yFDV7CWB5KdWdgjW3yKYvXd1Q42ZXFijFZNMuyy5SzChLX8aqMRqMXrFtiS1FJPZia3RE7qHkVV
```

必须先创建 ATA 否则铸造时会报错。有了 ATA 之后，往这个 ATA 中铸造 `99999` 个代币：

```bash
spl-token mint D4qHfYe6MDh1cfR6ikWDYqhFNgBoKMVVtX8Trs27C1Xp 99999
```

可以使用下面的命令查看当前钱包持有该代币的余额：

```bash
spl-token balance D4qHfYe6MDh1cfR6ikWDYqhFNgBoKMVVtX8Trs27C1Xp
```

将 `10` 个结算代币分发给 **拍卖行管理员账户**：

```bash
spl-token transfer D4qHfYe6MDh1cfR6ikWDYqhFNgBoKMVVtX8Trs27C1Xp 10 7M6Kfyk8qig6fGqDmwADbhkwwb3qCMCbYZ9ByY6NZGpv --allow-unfunded-recipient --fund-recipient
```

可以使用下面的命令查看其所持代币的余额：

```bash
spl-token balance D4qHfYe6MDh1cfR6ikWDYqhFNgBoKMVVtX8Trs27C1Xp --owner 7M6Kfyk8qig6fGqDmwADbhkwwb3qCMCbYZ9ByY6NZGpv
```

在创建拍卖行时的一次性创建费将由拍卖行管理员账户所持有的代币余额来支付。

将 `88888` 个结算代币分发给 **买家账户**：

```bash
spl-token transfer D4qHfYe6MDh1cfR6ikWDYqhFNgBoKMVVtX8Trs27C1Xp 88888 ERYupYod89YqmagL5Ga38f8n7ncfmriEvJbJ1SUdy5Ln --allow-unfunded-recipient --fund-recipient
```

可以使用下面的命令查看其所持结算代币的余额：

```bash
spl-token balance D4qHfYe6MDh1cfR6ikWDYqhFNgBoKMVVtX8Trs27C1Xp --owner ERYupYod89YqmagL5Ga38f8n7ncfmriEvJbJ1SUdy5Ln
```

竞拍费将由卖家账户所持有的结算代币余额来支付。

为 **卖家账户** 创建结算代币的 ATA（卖家用于收款，不需要有余额）：

```rust
spl-token create-account D4qHfYe6MDh1cfR6ikWDYqhFNgBoKMVVtX8Trs27C1Xp --owner BbwfLqqKy8V3FHJv1t4jgfRtMLPmnzdU1Afbo8JAPEnq --fee-payer ~/.config/solana/id.json
```

## 拍品 Mint Account

### NFT 拍品

使用下面的命令创建一个 Mint Account：

```bash
spl-token create-token --decimals 0
```

其输出如下：

```bash
Creating token AyAN3SQGYgxQUjuKpzWSS49oQD1EWhLyN1BV5RrebcUx under program TokenkegQfeZyiNwAJbNbGKPFXCWuBvf9Ss623VQ5DA

Address:  AyAN3SQGYgxQUjuKpzWSS49oQD1EWhLyN1BV5RrebcUx
Decimals:  0

Signature: 4a8y4XUqmtf1a4779Fpk5TtcewARs9RH4EBa2mqqeR6r4MB1VHXbxnY7X5XszfTUJcGTFWsmUdxwZBpoXjCPk2wo
```

为 **卖家账户** 创建该代币的 ATA：

```bash
spl-token create-account AyAN3SQGYgxQUjuKpzWSS49oQD1EWhLyN1BV5RrebcUx --owner BbwfLqqKy8V3FHJv1t4jgfRtMLPmnzdU1Afbo8JAPEnq --fee-payer ~/.config/solana/id.json
```

注意这里添加了 `--owner` 和 `--fee-payer`：

- **没写** `--owner` → 默认用 **fee payer（当前钱包）** 作为 owner，给自己创建 ATA。
- **写了** `--owner` → 你要替别人创建 ATA，必须 **用 fee payer 支付租金**，需要通过 `--fee-payer` 明确指定 fee payer。这里我们使用当前钱包。

其输出如下：

```bash
Creating account 7Yr8CQXz6aoxtNjg1SjUuM7oR7d5NrHEScHEN4hf8CQ1

Signature: 4UdbToo1Hnx5iStNrQscSvGDWZZkqnc83i8hQd9fYnS18ZYVu3ksxKndci8Zox6ezDe84zWNB37txXp3YxLtiHEP
```

必须先创建 ATA 否则铸造时会报错。有了 ATA 之后，往这个 ATA 中铸造 `1` 个代币：

```bash
spl-token mint AyAN3SQGYgxQUjuKpzWSS49oQD1EWhLyN1BV5RrebcUx 1 7Yr8CQXz6aoxtNjg1SjUuM7oR7d5NrHEScHEN4hf8CQ1
```

可以使用下面的命令查看当前钱包持有该代币的余额：

```bash
spl-token balance AyAN3SQGYgxQUjuKpzWSS49oQD1EWhLyN1BV5RrebcUx --owner BbwfLqqKy8V3FHJv1t4jgfRtMLPmnzdU1Afbo8JAPEnq
```

通过下面的命令来查看 Mint Account：

```bash
spl-token display AyAN3SQGYgxQUjuKpzWSS49oQD1EWhLyN1BV5RrebcUx
```

其输出如下：

```bash
SPL Token Mint
  Address: AyAN3SQGYgxQUjuKpzWSS49oQD1EWhLyN1BV5RrebcUx
  Program: TokenkegQfeZyiNwAJbNbGKPFXCWuBvf9Ss623VQ5DA
  Supply: 1
  Decimals: 0
  Mint authority: 3ZoojjwWCgArGREegaQgifwwtZF1EQdid5BjEX5weXah
  Freeze authority: (not set)
```

也可以在区块浏览器 [https://explorer.solana.com/](https://explorer.solana.com/) 中直接搜索 Mint 地址，就能看到。

对于 NFT，我们需要移除 mint authority，以锁定供应量：

```bash
spl-token authorize AyAN3SQGYgxQUjuKpzWSS49oQD1EWhLyN1BV5RrebcUx mint --disable
```

现在再查看该 Mint Account，其输出如下：

```bash
SPL Token Mint
  Address: AyAN3SQGYgxQUjuKpzWSS49oQD1EWhLyN1BV5RrebcUx
  Program: TokenkegQfeZyiNwAJbNbGKPFXCWuBvf9Ss623VQ5DA
  Supply: 1
  Decimals: 0
  Mint authority: (not set)
  Freeze authority: (not set)
```

这样我们就发行了一个 NFT 给卖家。

为 **买家账户** 创建该代币的 ATA：

```bash
spl-token create-account AyAN3SQGYgxQUjuKpzWSS49oQD1EWhLyN1BV5RrebcUx --owner ERYupYod89YqmagL5Ga38f8n7ncfmriEvJbJ1SUdy5Ln --fee-payer ~/.config/solana/id.json
```
