# 链上拍卖平台的设计思路

我们要实现一个链上拍卖平台，该平台允许任何人创建拍卖行，设定其拍卖行专属的运营规则。拍卖行相当于配置容器，其中记录了诸如抽成比例等，卖家选择一个拍卖行挂出一个或多个资产，定义拍卖规则如起拍价、底价、开始时间、结束时间等。平台会将卖家的资产锁定在托管账户中，买家参与竞拍，成交后平台将拍品转移给买家，将拍卖所得资金扣除平台费用和拍卖行费用，剩余的转给卖家。如果流拍，则将拍品退回卖家。

在线下，拍卖活动由拍卖行发起，卖家需要托管拍品给拍卖行，比如把画作、古董交给拍卖行仓库，以此保证竞拍期间不会赖账。拍卖行负责宣传、举办场次、制定规则、执行结算。拍卖行是一个中心化机构，它的品牌与信用背书保证了买卖双方的参与意愿。也就是说，监管和信任都集中在拍卖行这个可信的第三方。而链上的情况不同，链上资产不是实物，可交由合约托管，线下由工作人员维持的规则执行也都写进了合约逻辑中，任何调用都必须遵守这些规则。所有出价、成交价等也都记录在了区块链上，公开可查，不再依赖中心化机构来维持信任。

在链上，拍卖行是一个配置容器，决定了所有在它下面发生的交易活动的规则，比如手续费比例、抽成分配、白名单等。拍卖行必须由某个人先创建，没有拍卖行，卖家无法挂拍品。拍卖活动的创建权在卖家手里，卖家需要在某个拍卖行下把自己的资产锁进合约，发起一次拍卖活动。也就是说，卖家一旦在拍卖行中成功挂出拍品，就发起了一次拍卖活动。

在链上，所有能被拍卖的资产都必须是链上可验证的资产，例如 FT 或 NFT 的 Mint Account 地址，同时必须与卖家的账户绑定，从而能够确认其所有权的合法性。在发起拍卖时，卖家需要将资产从自己的 Token Account 转移到由合约控制的托管账户中，确保在竞价期间资产不会被随意挪用或撤回。只有当资产完全由智能合约掌控时，买家才敢出价，合约也才能在拍卖结束后自动执行结算逻辑，将拍品交付给中标买家，并将资金按规则分配给卖家、拍卖行和平台方。

平台方（Platform）作为链上拍卖程序的设计者和部署者，需要设置合理的盈利模式来维持平台自身的可持续发展。比如一次性收取拍卖行创建费，任何人要创建一个拍卖行，需要一次性支付费用。平台也可以对每一笔成交进行抽成，按拍品的成交价收取一定比例的费用，这既可以是固定分成，平台收取固定比例的手续费，也可以是阶梯分成，根据拍卖成交额设定阶梯式的分成模式，如成交额越高，平台收取的比例越低。另外也可以通过一些增值服务向拍卖行收取费用，比如提供前端模板、数据分析服务、开放 API 等。

拍卖行（Auction house）承载了一系列拍卖活动，围绕特定主题如图片、视频、游戏装备等 NFT 标的，以及现实世界资产映射（RWA）等链上资产，聚合资源，吸引卖家和买家，通过专业化、主题化、差异化，建立市场信任和用户群体，然后在此基础上变现。不同的拍卖行可以根据自身定位和目标市场来吸引不同的卖家和买家，形成差异化竞争。拍卖行的基本收入来源是交易手续费，从本行所有成交的拍品中，抽取成交价的一定比例。除此之外，一个有知名度的拍卖行，可以向卖家额外收取上架费和宣传费，就像苏富比线下拍卖，除了抽成外，还收取目录刊登费。

卖家（Lot creator）在某个拍卖行下提交拍品并定义拍卖参数如起拍价、底价、竞拍时间、拍卖类型（荷兰拍卖、英式拍卖等），拍品会被转入托管账户中，拍卖期间卖家无法动用。卖家收益为扣除平台费用和拍卖行费用后的部分。通过链上拍卖，卖家可能获得更高的市场出价。

买家（Bidder）参与拍卖过程，提交出价，通过竞争获得拍品。买家有机会以合理价格获得稀缺资产，进而在二级市场转售中获利。在线下拍卖中，对于竞拍人有一个保证金机制，竞拍人需要提交缴纳一笔保证金，缴纳后拍卖行会发给他一个号牌。如果竞拍人中标，保证金会直接计入总成交价中，剩余款项需在规定时间内支付。如果竞拍人未中标，保证金会在拍卖结束后退还。如果中标人不履约付款，拍卖行有权没收保证金，有些情况下还会对违约人追究责任，如列入黑名单、诉讼等。而在链上拍卖中，通常不需要事先缴纳单独的保证金。比如在英式拍卖中，每次出价就把资金锁进合约，确保出价有效。如果该出价比当前最高价高，这笔资金就成为新的最高价，保留在合约中，同时退还上一名最高价竞拍人的资金。如果该出价没有超过最高价，资金立即原路退还。这就是所谓的顶单托管模式（highest-bid escrow），每一笔出价都会先锁进合约，但最终只有最高价那一笔会一直留在里面，其他的要么立即退还，要么在被超越时退还。

另外，链上拍卖平台的币种支持也需要考虑。最直接的方式就是使用链的原生代币，比如在 Solana 链上就直接使用 SOL。目前拍卖平台最常见的是使用稳定币，其价格稳定，避免因 SOL 波动导致买卖双方承担额外风险。有些拍卖行会指定某个平台代币或社区代币作为结算货币。

以上内容就为拍卖平台提供了清晰的分层结构。

```
Platform → Auction House → Auction → Bidder
```

平台作为基础设施提供者，凭借抽成和创建费获利；拍卖行作为中间运营者，凭借交易手续费获利；卖家作为资产供给方，凭借拍卖收入获利；而买家虽然不是直接的盈利方，但却是整个生态运转的关键驱动力，他们通过不断的竞拍行为为整个系统注入活力。这样的结构确保了各方的利益关系得以平衡，且形成了一个可持续发展的生态闭环。
