# 结算相关的指令设计

Solana 程序只会在交易触发时执行，而不会自主运行，没有内置的调度机制如后台线程或定时器。因此，竞拍结束后必须有人发送结算指令，到点自动结算在 Solana 及其他公链上是无法实现的。

发送结算指令的方式，可以是用户手动触发，可以是卖家、赢家或者拍卖行，也可以是自动化机器人（Keeper）。在实际部署中，通常会由链下（off-chain）的中心化 bot 或去中心化的 Keeper 网络监控区块链状态，一旦发现某个拍卖结束，就会发送结算指令。

- **中心化 bot**：项目方自己维护服务器跑脚本定时监控，一旦竞拍结束自动发交易。
- **去中心化 Keeper 网络**：任何人都能运行 Keeper 节点，监听链上数据，当满足条件时竞相发交易，谁先触发谁获得奖励。比如 MakerDAO 的清算系统。
    
    $Keeper = 区块链世界里的 Bot$
    
    Bot 这个词太泛，用于各种场景（交易机器人、聊天机器人、爬虫等），Keeper 在 DeFi 里有特殊含义：强调守护和维护系统运行。
    

# 结算指令的账户上下文

```rust
#[derive(Accounts)]
pub struct SettleAuction<'a> {
    // 平台
    pub platform: Account<'a, Platform>,

    // 拍卖行
    #[account(has_one = platform)]
    pub auction_house: Account<'a, AuctionHouse>,

    // 拍卖
    #[account(
        mut,
        has_one = auction_house
    )]
    pub auction: Account<'a, Auction>,

    // 拍品托管账户
    #[account(
        mut,
        address = auction.escrow_asset_ata
    )]
    pub escrow_asset_ata: Account<'a, TokenAccount>,

    // 资金托管账户
    #[account(
        mut,
        address = auction.escrow_bid_ta
    )]
    pub escrow_bid_ta: Account<'a, TokenAccount>,

    // 拍卖行抽成账户
    #[account(
        mut,
        constraint = auction_house_treasury_ata.mint == auction_house.settlement_mint
    )]
    pub auction_house_treasury_ata: Account<'a, TokenAccount>,

    // 平台抽成账户
    #[account(
        mut,
        constraint = platform_treasury_ata.mint == auction_house.settlement_mint
    )]
    pub platform_treasury_ata: Account<'a, TokenAccount>,

    // 卖家
    #[account(
        address = auction.seller
    )]
    pub seller: SystemAccount<'a>,

    // 卖家的结算代币账户，用于收款
    #[account(mut)]
    pub seller_settlement_ata: Account<'a, TokenAccount>,

    // 卖家的拍品账户，用于退货
    #[account(mut)]
    pub seller_asset_ata: Account<'a, TokenAccount>,

    // 买家的结算代币账户，用于退款
    #[account(mut)]
    pub buyer_settlement_ata: Option<Account<'a, TokenAccount>>,

    // 买家的拍品账户，用于收货
    #[account(mut)]
    pub buyer_asset_ata: Option<Account<'a, TokenAccount>>,

    // Token Program
    pub token_program: Program<'a, Token>,
}
```

# 结算指令

**结算流程如下：**

- 判断拍卖结果（成交 / 流拍）
    
    **英式拍卖**：
    
    - 必须过了 `end_time` 才能结算。
    - 如果没人出价或出价 < 底价 → 流拍。
    - 否则 → 成交（价格 = 最高出价，买家 = 最高出价人）。
    
    **荷兰拍卖**：
    
    - 如果状态已经标记 `Sold`（有人买断） → 成交。
    - 否则必须过了 `end_time` 才能流拍。
- 根据结果做不同处理
    - 成交：把拍品转给买家、分配资金（平台、拍卖行抽成、卖家收益）
        - 把拍品转给买家。
        - 调用 `calculate_fees` 和 `distribute_fees`，把资金分给平台、拍卖行、卖家。
        - 更新拍卖状态：`status`、`final_price`、`buyer`。
    - 流拍：把拍品退回卖家、返还资金给出价人（如果有）
        - 把拍品退回给卖家。
        - 如果有出价，但未成交（例如低于底价），把托管资金退还给出价人。
        - 更新 `status` 为 `Unsold`，清空 `buyer`、`final_price`。

```rust
pub fn handler(ctx: Context<SettleAuction>) -> Result<()> {
    let auction = &mut ctx.accounts.auction;

    // 0. 校验：不能重复结算
    require!(
        auction.status != Some(AuctionStatus::Settled)
            && auction.status != Some(AuctionStatus::Unsold),
        error::ErrorCode::AuctionAlreadyFinalized
    );

    let outcome = determine_outcome(auction)?;

    match outcome {
        Outcome::Sold { price, buyer } => sold(ctx, price, buyer)?,
        Outcome::Unsold => unsold(ctx)?,
    }

    Ok(())
}

fn determine_outcome(auction: &Auction) -> Result<Outcome> {
    let now = Clock::get()?.unix_timestamp;
    match auction.auction_type {
        0 => {
            // 英式拍卖

            // 必须到期才能结算
            require!(now > auction.end_time, error::ErrorCode::AuctionNotEnded);

            if auction.english_highest_bid == 0
                || (auction.english_reserve_price > 0
                    && auction.english_highest_bid < auction.english_reserve_price)
            {
                // 流拍
                Ok(Outcome::Unsold)
            } else {
                // 已卖出
                Ok(Outcome::Sold {
                    price: auction.english_highest_bid,
                    buyer: auction.english_highest_bidder,
                })
            }
        }
        1 => {
            // 荷兰拍卖
            if auction.status == Some(AuctionStatus::Sold) {
                // 已卖出
                Ok(Outcome::Sold {
                    price: auction.final_price,
                    buyer: auction.buyer,
                })
            } else {
                // 无人买断

                // 此时需要检查时间，直到时间结束才能结算
                require!(now > auction.end_time, error::ErrorCode::AuctionNotEnded);

                Ok(Outcome::Unsold)
            }
        }
        // .into() 把 variant 转换成 ProgramError，这是 Anchor 要求的错误返回类型。
        _ => return Err(error::ErrorCode::InvalidAuctionType.into()),
    }
}

fn sold(ctx: Context<SettleAuction>, price: u64, buyer: Pubkey) -> Result<()> {
    let auction = &mut ctx.accounts.auction;

    // 拍品发送给买家
    let buyer_asset_ata = ctx
        .accounts
        .buyer_asset_ata
        .as_ref()
        .ok_or(error::ErrorCode::MissingBuyerAccount)?;

    transfer_with_pda(
        &ctx.accounts.escrow_asset_ata,
        buyer_asset_ata,
        auction,
        &ctx.accounts.token_program,
        auction.amount,
    )?;

    // 更新状态
    auction.status = Some(AuctionStatus::Settled);
    auction.final_price = price;
    auction.buyer = buyer;

    // 分配资金
    let fees = calculate_fees(price, &ctx.accounts.platform, &ctx.accounts.auction_house);
    distribute_fees(ctx, &fees)?;

    Ok(())
}

fn unsold(ctx: Context<SettleAuction>) -> Result<()> {
    let auction = &mut ctx.accounts.auction;

    // 拍品退还给卖家
    transfer_with_pda(
        &ctx.accounts.escrow_asset_ata,
        &ctx.accounts.seller_asset_ata,
        auction,
        &ctx.accounts.token_program,
        auction.amount,
    )?;

    // 资金退还给买家
    if auction.english_highest_bid > 0 {
        let buyer_settlement_ata = ctx
            .accounts
            .buyer_settlement_ata
            .as_ref()
            .ok_or(error::ErrorCode::MissingBuyerAccount)?;

        transfer_with_pda(
            &ctx.accounts.escrow_bid_ta,
            buyer_settlement_ata,
            auction,
            &ctx.accounts.token_program,
            auction.english_highest_bid,
        )?;
    }

    // 更新状态
    auction.status = Some(AuctionStatus::Unsold);
    auction.final_price = 0;
    auction.buyer = Pubkey::default();

    Ok(())
}

fn calculate_fees(price: u64, platform: &Platform, auction_house: &AuctionHouse) -> Fees {
    // 计算平台抽成
    let platform_fee = price * (platform.platform_fee_rate as u64) / 10_000;
    // 计算拍卖行抽成
    let auction_house_fee = price * auction_house.fee_rate as u64 / 10_000;
    // 卖家实得
    let seller_fee = price - platform_fee - auction_house_fee;

    Fees {
        platform_fee,
        auction_house_fee,
        seller_fee,
    }
}

fn distribute_fees(ctx: Context<SettleAuction>, fees: &Fees) -> Result<()> {
    let auction = &ctx.accounts.auction;

    // 1. 平台抽成
    if fees.platform_fee > 0 {
        transfer_with_pda(
            &ctx.accounts.escrow_bid_ta,
            &ctx.accounts.platform_treasury_ata,
            auction,
            &ctx.accounts.token_program,
            fees.platform_fee,
        )?;
    }

    // 2. 拍卖行抽成
    if fees.auction_house_fee > 0 {
        transfer_with_pda(
            &ctx.accounts.escrow_bid_ta,
            &ctx.accounts.auction_house_treasury_ata,
            auction,
            &ctx.accounts.token_program,
            fees.auction_house_fee,
        )?;
    }

    // 3. 卖家实得
    transfer_with_pda(
        &ctx.accounts.escrow_bid_ta,
        &ctx.accounts.seller_settlement_ata,
        auction,
        &ctx.accounts.token_program,
        fees.seller_fee,
    )?;

    Ok(())
}

fn transfer_with_pda<'a>(
    from: &Account<'a, TokenAccount>,
    to: &Account<'a, TokenAccount>,
    auction: &Account<'a, Auction>,
    token_program: &Program<'a, Token>,
    amount: u64,
) -> Result<()> {
    let auction_id_bytes = auction.auction_id.to_le_bytes();
    let seeds = &[
        b"auction",
        auction.auction_house.as_ref(),
        auction_id_bytes.as_ref(),
        &[auction.bump],
    ];

    let signer_seeds = &[&seeds[..]];

    let cpi_accounts = Transfer {
        from: from.to_account_info(),
        to: to.to_account_info(),
        authority: auction.to_account_info(),
    };
    transfer(
        CpiContext::new_with_signer(token_program.to_account_info(), cpi_accounts, signer_seeds),
        amount,
    )
}
```
